# RateruPAD（お試し版）

案件進捗・見積と請求・図面と写真・工程と予定・日報・売上管理をまとめて使う、RateruPAD のお試し版です。

- アプリ：`index.html`（入れた内容は、開いた端末の中にだけ保存されます）
- 使い方：`manual.html`（画像つき。アプリの左のメニュー「📖 使い方」からも開けます）
- 説明書：`manual-phone.pdf`（スマホ版）／`manual-pc.pdf`（パソコン版）／`overview.pdf`（ご紹介）。アプリを新しくするたびに作り直しています

新しく開いた端末では見本なしで始まります。入力内容はその端末のブラウザ内だけに保存されます。
